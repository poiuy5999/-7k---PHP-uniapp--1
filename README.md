点餐系统后端采用 PHP 开发，前端基于 UniApp 全开源构建，一套前端代码可编译微信小程序、H5、APP，专为多门店连锁餐饮打造，支持堂食扫码点餐、外卖配送、到店自提，适配连锁店统一管控 + 门店独立运营的业务模式。

系统架构分为总管理后台、门店后台、用户端三端。平台总后台实现连锁统一管理：门店新增与状态管控、菜品库统一维护、价格分组、权限分配、全连锁营业数据汇总，支持总部统一配置营销活动，也可下放权限让门店自主微调。门店后台可独立管理本门店菜品、库存、桌台、订单、小票打印，查看门店营收报表，单独设置配送范围、起送价与配送费。

顾客端支持扫码桌码堂食点餐、外卖下单、购物车、微信支付、优惠券、会员积分、订单查询。UniApp 跨端特性，满足顾客在小程序、H5 多渠道下单，方便连锁门店多渠道引流。系统支持菜品规格、套餐、满减、储值等营销功能，可开启订单代付、前台收银，兼顾线上线下收银场景。

项目代码完全开源，无代码加密。PHP 后端采用主流框架，代码结构清晰，便于二次开发；UniApp 前端组件化开发，页面、交互可自由修改。数据库设计支持门店数据隔离，保证各门店订单、客户数据独立，总部统一汇总统计。

部署需准备服务器、域名、数据库，配置 PHP 运行环境，导入数据库，对接各小程序以及支付接口，配置短信、打印插件。部署完成后总部录入基础菜品库，分配门店账号，各门店完善菜品图片与门店参数，测试下单、支付、打印功能，提交平台审核上线。

开源使用务必阅读开源协议，区分学习使用与商用授权。上线前做好安全防护，防止 SQL 注入、越权访问，做好支付校验，保障订单与资金安全。该方案适合连锁餐饮企业、本地餐饮服务商私有化部署，自主掌控所有业务数据，灵活迭代业务功能。
